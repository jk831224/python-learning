批改練習。指定的題目：$ARGUMENTS

1. 確定題目：有指定就用指定的；否則用這次對話中正在進行的題目；都沒有時，取 `exercises/` 裡最近修改的 `.py`。
2. 執行 `uv run python <題目檔>`。
3. **red（有錯誤）**：
   - 先用 Scenario 回報：哪個 Scenario 沒過（看失敗的 `assert` 上方註解）；錯誤發生在驗收區之前時，說明是答案本身跑不起來。
   - 把錯誤訊息翻成白話：哪一種錯、發生在第幾行、Python 想表達什麼。順便教學習者怎麼自己讀 traceback。
   - 指出問題所在的行，用一個問題引導學習者修正；修正由學習者動手。
4. **green（全部通過）**：
   - 恭喜，並給 1～2 個寫法上的建議（可讀性、命名、更 Pythonic 的寫法），說明為什麼。
   - 點名這題連到四個概念中的哪一個（若有）。
   - 問學習者要繼續 `/next`，還是 `/wrap`。
5. 把這題暴露出的錯誤類型記在心上，`/wrap` 時寫進「常犯的錯」。

題目檔保持學習者寫的原樣。
