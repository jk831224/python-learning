argument-hint: [想練的概念（可省略）]
---

出下一題練習。學習者指定的概念：$ARGUMENTS

1. 讀 `PROGRESS.md`，找出目前專案下一步需要、但學習者還沒掌握的**一個**概念。若學習者有指定，就用指定的。尚無專案時，以專案 (a) 會用到的基礎為準（函式優先）。
2. 用一句話告訴學習者：這題練什麼、為什麼專案需要它。
3. 建立 `exercises/<概念英文名>/<兩位數序號>_<題目英文 slug>.py`，序號接續該資料夾現有的題目。檔案格式：

   ```python
   """
   題目：<一句話標題>
   練習概念：<概念>
   為什麼要學：<連到專案的哪一步>

   情境：<生活或工作情境>
   要求：<要寫出什麼>
   範例：<輸入 → 預期輸出>
   """

   # === 你的答案（從這裡開始寫）===


   # === 答案結束 ===

   # === 驗收（不用改）===
   assert ...
   print("✅ 全部通過")
   ```

   驗收的 `assert` 至少要有一個一般情況、一個邊界條件。題目只引入一個新概念，其餘只用學習者已掌握的語法。
4. 執行 `uv run python <題目檔>`，確認在答案空白時會失敗（**red**）。
5. 告訴學習者檔案路徑與執行指令，然後停下來，等學習者作答。

完成條件：題目檔存在、空白狀態下執行為 red、學習者知道怎麼執行。
